 Result Summary UI

A clean and responsive **Result Summary** interface built as a frontend practice project. The project focuses on recreating a polished results screen from a provided design while maintaining accurate spacing, typography, colors, and responsive behavior.

The interface presents an overall score together with individual category results in a structured and visually appealing layout.


 ✨ Features

* Clean and modern result summary interface
* Overall score display
* Category-based result breakdown
* Individual category scores
* Category icons and supporting information
* Responsive layout
* Mobile-friendly design
* Desktop layout optimization
* Custom CSS styling
* Visual hierarchy matching the original design
* Reusable and organized frontend structure

 📊 Result Summary

The interface presents a user's results through two main areas:

 Overall Result

Displays the user's overall performance through:

* Total score
* Maximum possible score
* Performance summary
* Supporting text

 Category Breakdown

Individual categories are displayed with their respective scores.

The category-based layout makes it easy for users to understand their performance at a glance.

 🖥️ Responsive Design

The layout adapts to different screen sizes while maintaining the structure and readability of the original design.

On smaller screens, the content transitions into a mobile-friendly layout with adjusted:

* Spacing
* Typography
* Component dimensions
* Content alignment
* Section arrangement

 🛠️ Tech Stack

* HTML5 — Semantic page structure
* CSS3 — Styling and responsive design
* JavaScript — Frontend functionality

 📦 Installation

 1. Clone the repository

git clone https://github.com/zoha39/ResultSummary_UI.git


 2. Navigate to the project

cd ResultSummary_UI


 3. Run the project

Open `index.html` directly in a browser.

For development, you can also use the **Live Server** extension in VS Code.
